# 表格探针

`dev/probe/probe.py` 会把这页拷进临时 vault 里量。改这里的内容就能改探针的观测对象。

要求：

- **长格**：一整段中文，长度最好落在「折行点」附近 —— 字距一变（0.01em = 0.16px/字）
  折行就会跳，检查 1 才灵敏。下面这格 33 字就是这么挑的（原本是用户笔记里的真实内容）。
- **短格**：几个字即可，用来量单行行高与单元格内边距（检查 2 在两个视图里比它）。
- 检查 1/2 只认 **DOM 里的第一张表**（`tables[0]`）—— 所以下面那两张给检查 3 用的
  表**必须排在这张后面**。换内容时请保持这些性质（或直接把探针的判定当
  「同等布局下前后比」，别动窗口大小）。

| 类别 | 说明 |
| --- | --- |
| 工具与技术 | 项目管理计划（进度管理计划、范围基准）、事业环境因素、组织过程资产 |
| 专家判断 | 短文本 |
| 数据分析 | 项目管理计划（进度管理计划、范围基准）、事业环境因素、组织过程资产 |
| 会议 | 另一段比较长的说明文字，用来观察折行与对齐 |

检查 3 要的三种列数（`--folio-table-cols` 默认 4）：上面那张 **2 列** = 「≤ 设定值」，
下面 **4 列** = 正好等于设定值（边界），**6 列** = 「> 设定值」（该滚的那一侧）。
